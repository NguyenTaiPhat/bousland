# BousLand v1.0.7 Implementation Plan: Fluid Notch, Ambient Glow & Smooth Tab Transitions

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement BousLand v1.0.7 featuring ambient edge glow with state priority, zero-react-render liquid aurora audio visualizer with EMA smoothing, time-delta jelly drag physics, accessible reduced-motion support, sliding pill tab indicators, and anchor-aware blur-free panel morphing.

**Architecture:** A standalone state machine evaluates prioritized aura illumination; native WASAPI spectrum streams to an unreactive buffer rendered via a direct `requestAnimationFrame` Bézier canvas/SVG loop (avoiding React tree re-renders); drag physics uses normalized `performance.now()` time-delta and exponential velocity smoothing; panel transitions morph from dock-anchored origins with zero GPU blur filters; and Framer Motion `layoutId` drives fluid tab navigation.

**Tech Stack:** React 19, TypeScript, Framer Motion, Tauri 2, Vitest, Rust / WASAPI.

## Global Constraints
- Target version: 1.0.7 across `package.json`, `src-tauri/Cargo.toml`, and `src-tauri/tauri.conf.json`.
- Zero React component re-renders per audio frame: audio spectrum must update via unreactive buffer + RAF loop.
- No `filter: blur(8px)` in expanding/morphing panels to preserve 60-120fps GPU performance on Windows.
- Full accessibility support for `prefers-reduced-motion`.
- All 5 dock positions (`TOP_CENTER`, `LEFT`, `RIGHT`, `TOP_LEFT`, `TOP_RIGHT`) must have verified boundary and flat-edge compliance.
